# Windows 11: FreeLLMAPI + Claude Code

This guide is for the Windows desktop build. It does not require Docker or a local model.

## 1. Install and start FreeLLMAPI

1. Download the Windows x64 **FreeLLMAPI-Setup** installer from the [latest desktop release](https://github.com/tashfeenahmed/freellmapi/releases/latest).
2. Install and launch it. Keep it running in the Windows system tray.
3. Open its dashboard and confirm the API is running at `http://127.0.0.1:31415`.

## 2. Add provider keys (one-time account step)

FreeLLMAPI is a router, not a source of provider credentials. Each provider issues its own API key after you create/sign in to an account and accept that provider's terms. The installer cannot lawfully or technically create those credentials on your behalf.

1. In the dashboard, open **Keys**.
2. Use **Add key** and choose a provider.
3. Create the provider key using the signup link shown in the dialog, paste it into FreeLLMAPI, and save.
4. Repeat for any additional providers you want. Start with one provider; you can add more later.
5. Open **Keys → API Key** and copy the **Unified API Key**.

Do not share provider keys or the Unified API Key in chat, screenshots, or public repositories. Keep the encryption key and database local.

## 3. Connect Claude Code without the npm setup command

The helper below merges the FreeLLMAPI endpoint into your existing Claude Code settings and makes a timestamped backup first.

1. Download [connect-claude-code.ps1](https://raw.githubusercontent.com/kitefreaks3-collab/freellmapi/ayush/windows-one-click-setup/scripts/windows/connect-claude-code.ps1).
2. Open PowerShell in the downloaded file's folder.
3. Run:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\\connect-claude-code.ps1
   ```

4. Paste the Unified API Key when prompted.
5. Restart Claude Code.

The helper defaults to `http://127.0.0.1:31415`, preserves unrelated Claude settings, and creates a backup before changing the file. If your FreeLLMAPI dashboard shows a different port, pass it with `-BaseUrl`.

## Important limitations

- A provider's free tier has its own rate limits, daily/monthly caps, model restrictions, and eligibility rules. The advertised aggregate capacity is not a guaranteed balance on one account.
- The helper configures Claude Code's endpoint; it does not install Claude Code itself.
- Do not use a paid Anthropic account key as the FreeLLMAPI Unified API Key. Use the key generated by FreeLLMAPI.
